# TBook Hotel

## Project Description
A responsive hotel website and room-booking front end built with React JS. Pages: Home, About, Rooms and Contact (with a validated contact form). Theme: black and red.

## Technologies Used
React JS, React Router, Vite, JavaScript, HTML, CSS

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run: `npm install`
4. Start the application: `npm run dev`

## Deployment (GitHub Pages)
Push to the `main` branch. The workflow in `.github/workflows/deploy.yml` builds and publishes the site. In the repository, open Settings > Pages and set Source to GitHub Actions.
